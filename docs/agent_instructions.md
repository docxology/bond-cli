# Agent Instructions — bond-cli (THE FRONT DOOR)

Read this before modifying any file in `projects/working/bond/bond-cli/`.
These are hard constraints, and each states the consequence of violating it.

## Rule 1 — Delegate, never re-implement

The front door dispatches to built layers; it does not implement their logic.

- A mission stage (`brief`/`recon`/`plan`/`execute`/`debrief`) loads the film's
  `MissionProvider` via `bond_api.discovery.load_provider` and calls it.
- `run` resolves a mission from `bond_orchestrator.missions` and executes it
  with `bond_orchestrator.runner.MissionRunner`.
- `list`/`status`/`whois`/`roster-export` read `bond_coordinator.registry` and
  `bond_coordinator.status`.
- `gadgets` builds a `bond_api.registry.GadgetRegistry`.
- `missions` reads `bond_orchestrator.missions`.

**Consequence of violation:** duplicated logic drifts from the source of truth;
the fleet's single implementation is no longer single.

## Rule 2 — Never change the consumed contract

`bond-cli` ships no `mission.py`. It reads the frozen `bond_api` surface —
`brief/recon/plan/execute/debrief`, `run_mission`, `GadgetRegistry` — and the
`GADGETS` conventions the films use. Do not add a stage, rename a field, or
reinterpret `MissionOutcome.success` here.

**Consequence of violation:** a fork of the protocol at Layer 4; 27 film
packages and three sibling layers immediately disagree with the front door.

## Rule 3 — Thin scripts, real `src/`

`scripts/bond.py` bootstraps `src/` onto `sys.path` and calls
`bond_cli.dispatch.main`; `scripts/z_generate_manuscript_variables.py` calls
`manuscript_variables.generate_variables`. Neither contains logic.

## Rule 4 — Zero mocks

No `unittest.mock`, `MagicMock`, `@patch`, or `create_autospec` anywhere in
`tests/`. Tests use **real** film providers (the numpy-free reference film
`sable`, and real fleet films `goldfinger`/`skyfall`), **real** importable film
packages written into `tmp_path`, **real** gate manifests on disk, and **real**
subprocess invocations of `scripts/`.

`monkeypatch.setattr` on this package's own module constants (`BOND_ROOT`,
`GATE_MANIFEST`, `GADGET_FILM_SLUGS`) is environment isolation, not mocking —
it redirects real file reads at real files. Do not use it to replace a
dependency's behaviour with a stand-in.

## Rule 5 — Pin ambient fleet state

Any test whose result depends on the aggregate gate manifest must point
`dispatch.GATE_MANIFEST` at a `tmp_path` file (present or deliberately absent).
The real fleet manifest at `<bond root>/output/aggregate/gate_manifest.json`
appears and disappears as the fleet gate runs.

**Consequence of violation:** the suite passes or fails depending on whether
someone last ran the fleet gate, and branch coverage silently moves with it.

## Rule 6 — Deterministic

- Film providers are fixed-seed and side-effect free.
- Output ordering is canonical (roster order, sorted JSON keys).
- No wall-clock data in any persisted artifact — `status --json` deliberately
  has no `generated_at` field, and a test asserts its absence.
- Assert key ordering on the **raw emitted text**
  (`tests/test_contracts.py::_key_orders`). `json.loads(out)["x"] == y`
  discards order, so it cannot see `sort_keys` being dropped.

## Rule 7 — Coverage gate

`src/` must hold ≥90% line+branch coverage:

```bash
uv run pytest tests/ --cov=src --cov-fail-under=90
```

Live count + coverage % are in [`_generated/COUNTS.md`](_generated/COUNTS.md).
Do not quote a coverage figure anywhere else — cite the gate or that file.

The gate measures execution, not verification. Coverage emits no branch arc for
a conditional expression, so a high percentage can coexist with a completely
unbound claim — it did here, for the whole exit-code contract. Treat the
percentage as necessary, never sufficient.

## Rule 8 — Exit codes

`0` success, `1` command failure (unknown film, non-passing
execute/debrief/run, empty gadget lookup), `2` argparse misuse and unknown
mission. Test failures with `dispatch.main([...])` returning the code, and
argparse misuse with `pytest.raises(SystemExit)`.

Every `return 0 if <predicate> else 1` needs a test that drives the predicate
**false** — otherwise the non-zero arm is unverified no matter what the
coverage percentage says. `tests/test_contracts.py` holds those cases (real
film packages whose `execute` genuinely fails), each paired with a passing
positive control.

## Rule 9 — Every number is derived

`{{TOKEN}}`s are generated by `src/bond_cli/manuscript_variables.py` from
`manuscript/config.yaml` (`package:`/`paper:`) plus the coordinator roster, the
orchestrator mission registry, and `dispatch`'s own `COMMANDS` /
`JSON_COMMANDS` / `DEPENDENCY_LAYERS` tuples. Never hand-author a count in
manuscript prose, and add a matching row to `data/claim_ledger.yaml` — the
suite re-derives every ledger row from the symbol it names.

**Consequence of violation:** exactly the defect Phase 5 found — a ledger that
said the CLI had nine subcommands while it had twelve.
