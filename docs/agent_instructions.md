# Agent Instructions — bond-cli

Read this before modifying any file in `projects/working/bond/bond-cli/`.
These are hard constraints, and each has a consequence if violated.

## Rule 1 — Delegate, never re-implement

The front door dispatches to built layers; it does not implement their logic.

- A mission stage (`brief`/`recon`/`plan`/`execute`/`debrief`) loads the film's
  `MissionProvider` via `bond_api.discovery.load_provider` and calls it.
- `run` resolves a mission from `bond_orchestrator.missions` and executes it
  with `bond_orchestrator.runner.MissionRunner`.
- `list`/`status` read `bond_coordinator.registry`/`bond_coordinator.status`.
- `gadgets` builds a `bond_api.registry.GadgetRegistry`.

**Consequence of violation:** duplicated logic drifts from the source of truth;
the fleet's single implementation is no longer single.

## Rule 2 — Thin scripts, real `src/`

`scripts/bond.py` bootstraps `src/` onto `sys.path` and calls
`bond_cli.dispatch.main`; it contains no logic. All routing lives in
`src/bond_cli/dispatch.py`.

## Rule 3 — Zero mocks

No `unittest.mock`, `MagicMock`, `@patch`, or `create_autospec` anywhere in
`tests/`. Tests use **real** film providers (the light reference film `sable`
for the protocol lifecycle, a real fleet film like `skyfall` for gadgets) and
real subprocess invocations of `scripts/bond.py`.

## Rule 4 — Deterministic

- Film providers are fixed-seed and side-effect free.
- Output ordering is canonical (roster order, sorted result keys).
- No wall-clock data in any persisted artifact.

## Rule 5 — Coverage gate

`src/` must hold ≥90% line+branch coverage:

```bash
uv run pytest tests/ --cov=src --cov-fail-under=90
```

Live count + coverage % are in `docs/_generated/COUNTS.md`.

## Rule 6 — Exit codes

`0` success, `1` command failure (unknown film, non-passing execute/debrief,
failed run, empty gadget lookup), `2` argparse misuse. Test with
`pytest.raises(SystemExit)` + `capsys`.

## Rule 7 — Manuscript tokens from config + registry

`{{TOKEN}}`s are generated by `src/bond_cli/manuscript_variables.py` from
`manuscript/config.yaml` (`package:` identity) and the coordinator registry.
Never hand-author fleet counts in prose.
