# bond-cli

The PROJECT BOND command line routes film lifecycle stages, multi-package
missions, roster queries, and gadget lookup to the built layers.

```sh
uv sync --locked
uv run --no-sync bond list
```

The [documentation](docs/README.md) covers installation, the command reference,
fleet setup, testing, and manuscript rendering. Read the
[software manuscript](docs/manuscript/README.md) for the design and evidence.
